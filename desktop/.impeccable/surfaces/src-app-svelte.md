# Crush Desktop main screen

## Scope and visitor mode
- The main window: chat list (left), conversation (middle), visuals panel with the limits row (right). Mode: Operate.
- Approved comp: `.impeccable/mocks/decision/edition.png` (option one, kept as picked, 2026-10-18). Frame 1600x992; the app opens at Compact (chat text about 15 px; Ctrl + and Ctrl - in even steps; Ctrl 0 back to Compact).
- Owner-approved exceptions to the comp: the wordmark is the owner's original CRUSH (heavy extended capitals with a grey AI, PRODUCT.md), set in iron black on bone, not the comp's small-caps serif; each of the three columns can be widened or narrowed by dragging its edge, and the others adjust (widths remembered, like the chat list's collapsed state).

## Audience, job, constraints
- One owner: a software-engineering student running several AI coding agents at once across many projects, beside the terminal app, on KDE Plasma (KDE title bar; 2560x1440 at 170 Hz), with a Mac build for occasional use.
- Job: follow several live chats, branch from highlighted words, read folded tool work, and always see model, context and limits.
- Pinned layout (PLAN.md sections 2 and 15): three columns; model and effort in the typing box; context, 5-hour and weekly bars in one row under the project name at the top of the right panel (under the typing box when that panel is hidden); helpers tray above the typing box; asks take the typing box's place.
- Banned: purple-to-blue gradients, glow or glassy effects, emoji icons, a green main colour, everything in rounded cards, AI sparkle icons, misaligned text or icons.
- Bar: as tidy as Zed, with a little more dazzle than Zed has.

## Chosen direction and memorable moment
- Scholar's Edition, the dealt challenger rw-centre-rail-reference-setting from re-roll round 2, chosen by the owner as drawn.
- Memorable moment: a thin vermilion rail down the conversation's left edge carries lettered keys where the chat branches and where tools ran.

## Direction contract
THESIS: Crush set like a fine reference edition: bone paper, hairline ruling, and a vermilion rail of lettered keys where each chat branches or tools ran. It refuses the category default of a charcoal sidebar, chat bubbles and one accent colour.

OWN-WORLD: Bone paper, iron-black ink, slate and ash greys; rubric vermilion only for keys, the rail, the selected chat's rule and the send key; amber only for warnings. A Miller-style text serif, small-caps apparatus labels, monospace for paths. Every rule a one-pixel hairline with small plus-mark corners; no radius, no shadow.

STORY: The owner sees every live chat, its branches and its state at a glance, reads the conversation like a well-set page, branches from any phrase, and the rail shows where the chat changed footing.

FIRST VIEWPORT: Three columns. Left: the owner's CRUSH wordmark (heavy extended capitals, grey AI) in iron black, New chat, search, Today's chats; the selected chat ruled in vermilion with its branches beneath. Middle: title, small-caps path, messages set on the page without bubbles, the rail with key B at "SameSite=Strict" and key C at the folded tool row, the typing box with model and a vermilion send key. Right: project name, the three limit readings in one row, then Visuals in hairline frames.

FORM: catalog world rw-centre-rail-reference-setting, a dealt challenger (not on the grounded list; the roll assigned candidate 3 of 7, the chess book); seed: seed:d55921922e855d5a.
