# Crush Desktop: feature checklist

Every terminal-app (TUI) feature, traced to the code, with its desktop version, the check that proves it, the proof, and its status. Source: four read-only code surveys (953 rows), merged and audited (see the summary below). Status values: `todo`, `built` (built, check not yet passing), `done` (check passing, proof linked), `left out` and `command line only` (approved exceptions, PLAN.md §12).

**Phase 7 sweep (2026-10-19):** 191 rows `done` (a passing test names the row or its planned check), 654 `built`, 11 `left out`, 6 `command line only`, none `todo`. `built` means the screen or behavior exists in the app but no test proves that row: waves 2 and 3 (PAL, MOD, AUTH, SES, ASK, EXT, SET, THM, VIEW, SHARE, SYS) were built without tests on the owner's instruction; wave 1 rows (KIT, LST, LIVE, TERM) are covered in part by their window drivers, not row by row. The sweep went by the row map in `docs/desktop-design-5-6.md` and by row IDs cited in passing tests; it did not re-test each row.

Columns added for the build: **Desktop version** (`same behavior`, a pointer to the desktop design in PLAN.md §7, or an approved exception), **Check** (the test that proves it), **Proof** (screenshot or log under `desktop/docs/evidence/`), **Status**.


This checklist merges the four feature lists of the terminal app (t1-main M1–M216, t2-dialogs D001–D465, t3-chat C1–C119, t10-settings S1–S153; 953 source rows) into 834 merged rows; an audit pass then brought it to **862 rows**: START 21, LIST 56, CHAT 113, TYPE 61, SIDE 35, LIVE 21, CMD 64, DLG 311, SET 37, THEME 82, NOTE 9, REM 19, UPD 8, MISC 25. 249 source IDs were merged into shared rows (rows with more than one source), so the merge had 119 rows fewer than the sources. 18 source IDs that covered several features on their own appear in more than one row on purpose (984 source mentions in total). Every one of the 953 source IDs appears in at least one "From" cell. The audit pass added 14 rows the audit found (From "audit") and 13 rows found while closing its gaps (From "audit2"), and corrected 13 rows in place (LIST-006, LIST-007, LIST-020, LIST-030, CHAT-100, SIDE-033, LIVE-007, DLG-245, DLG-287, SET-009, START-019, REM-007, MISC-006) and settled conflict 20. 66 rows are terminal-only and 14 partly; see the list at the end. 4 likely terminal-app bugs are listed in their own section. A re-check of the audit pass (2026-10-18) confirmed all fixes, corrected LIST-040 and LIST-051, added LIST-056 (cursor), and found SIDE-035 is not a visible bug (the short help line is never drawn). There are 27 conflicts or doubts, listed before that; several were settled by reading the code.

How to read the evidence column. The paths come from the four source lists unchanged:
- **M rows** (t1-main): bare file names such as `keypress.go:17` are in `internal/ui/model/`; `completions/…`, `attachments/…`, `util/…` and `dialog/…` are under `internal/ui/`.
- **D rows** (t2-dialogs): full paths from the repo root.
- **C rows** (t3-chat): paths are under `internal/ui/` (`chat/…`, `common/…`, `list/…`, `styles/…`, `diffview/…`); a bare file name continues the folder of the path before it.
- **S rows** (t10-settings): paths are under `internal/` (`cmd/…`, `config/…`, `ui/sessionhost/…`), and session-host files like `host.go`, `input.go`, `draw.go` are in `internal/ui/sessionhost/`. "file" means the source author knew the file but not the line.
- **audit / audit2 rows** (and evidence added by the audit pass): full paths from the repo root, except where a cell continues the source row's own short paths.

All paths are relative to `/home/braxtenchenay/dev/crush`. "TO" below means terminal-only.
